REST --> Representational State Transfer 

*HTTP Methods*

1. GET --> To get some resources from the server side. It does not modify data on the server.

2. POST --> To add resources on server *Creating User account, adding a comment on instagram*

3. PUT --> To update a resource by replacing it with new data. A complete change of previous representation *For updating whole account of a user*

4. PTACH --> To update a resource partially modifying it. *for updating only email*

5. DELETE --> Delete a resource.







POSTMAN --> Used to build, test, document and manage APIs.It acts as a graphical interface that allows developers and testers to send direct HTTP/HTTPS requests to servers and inspect the responses without needing to write complex code.
